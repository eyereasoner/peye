Every case of the conformance suite, run against peye in your browser and checked against the specification. Back to the playground

Starting Python… peye

Each case runs peye's command line on the files it names, in a directory of its own, and compares what peye prints and its exit code with what the specification requires. In an expected line, … stands for text the specification leaves to the implementation. Run the same cases against any implementation with python conformance/run.py --command "…".

Powered by peye, a dependency-free Python rule language with forward and backward reasoning and checkable proofs.
